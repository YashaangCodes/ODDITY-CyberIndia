# ODDITY Cyber India

**Find what doesn't fit.**

ODDITY Cyber India is a digital anomaly investigation system that helps users
investigate potentially suspicious:

- Messages
- Phone numbers
- URLs

Submitted information is analyzed against a set of rule-based indicators to
identify suspicious signals, calculate a risk score, and explain the reasons
behind the result.

## What This Is (and Isn't)

ODDITY Cyber India is an **investigation and analysis tool**. It does not
claim to remove malware, block incoming threats, or provide real-time
protection. Its purpose is to help a user reason about something they've
already received — a message, a phone number, a URL — before they act on it.

## Project Status

This project is under active development. The backend currently provides
three rule-based analysis features (message, phone number, and URL
analysis) via a FastAPI API. Frontend development has not yet begun.

Detailed frontend documentation will be added once the frontend is designed.
